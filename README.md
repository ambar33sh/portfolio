# Ambareesh Kannan — Spatial OS 26 Portfolio 🚀

An ultra-futuristic **iOS 26 / VisionOS Glassmorphism Spatial Operating System** portfolio built with **React**, **Three.js / React Three Fiber**, **Tailwind CSS**, and **Framer Motion**.

## 🌟 Highlights & Features

- **iOS 26 Frosted Glass Engine**: Multi-layer specular glass with blur saturation, glowing iridescent accents, and dynamic ambient lighting.
- **3D Spatial Particle Cosmos**: Interactive Three.js dual-layer particle field with mouse-tracking parallax and floating geometric glass nodes.
- **Interactive Avatar & Profile HUD**: Dedicated avatar space with live client-side photo upload and persistent storage.
- **Full Resume / CV Applications**:
  - **Projects Explorer**: Deep-dive showcases for *Glint & Gaze*, *Project Hairdo*, and *Reverse Logistics GenAI*.
  - **Experience & Training**: AI Technical Trainer at *Outlier AI & Soul AI* (Technical QA & LLM Evaluation).
  - **Skills Matrix**: Interactive categorized technical competencies with live search and animated progress tracks.
  - **Certifications Hub**: Verified credential cards for *Oracle OCI GenAI Pro*, *OCI AI Foundations*, *NPTEL Deep Learning*, *Cloud Computing*, *Udemy DSA*, and *Coursera C++*.
  - **Interactive AI Terminal**: Live CLI emulator with custom commands (`help`, `skills`, `projects`, `sudo hire ambareesh`, `contact`).
  - **Contact Center**: 1-click clipboard copy for email & phone, direct social links, and working transmission form.
  - **Curriculum Vitae Viewer**: Formatted CV document sheet matching standard resume layout with built-in print / save-as-PDF action.
- **Spatial UI Controls**: VisionOS-style status bar, Spotlight Search (`Cmd/Ctrl + K`), synthesized Web Audio sound effects, and floating glass Dock.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Custom Glassmorphism CSS Tokens
- **3D & Motion**: Three.js, `@react-three/fiber`, `@react-three/drei`, Framer Motion, Maath
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizer

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/ambar33sh/spatial-os-portfolio.git

# Navigate to project directory
cd spatial-os-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🌐 Deploy to Vercel (Recommended)

1. Push this project to your GitHub repository.
2. Sign in to [Vercel](https://vercel.com) with GitHub.
3. Click **"Add New Project"** and select this repository.
4. Click **Deploy** (Vite settings are pre-configured).
